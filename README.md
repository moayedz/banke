# بنكي 🏦

أداة شخصية لتتبّع المصاريف. بتشتغل **على الماك تبعك**، وبتفتحها من الآيفون كأنها تطبيق.
كل بياناتك بملف واحد على جهازك (`data/banke.db`)، وما بتنبعت لأي سيرفر.

## شو فيها (النسخة الأولى)

- لوحة رئيسية: الداخل والطالع والصافي هالشهر، صافي الثروة، المصاريف حسب الفئة، والمصاريف اليومية.
- إضافة معاملة يدوي (ليرة أو دولار)، وتعديلها وحذفها.
- **استيراد كشف حساب** Excel (`.xlsx` / `.xls`) أو CSV من Kuveyt Türk وVakıfBank أو أي بنك.
  بيفهم الأعمدة لحاله (Tarih / Açıklama / Tutar / Borç / Alacak)، وإذا استوردت نفس الكشف مرتين ما بيكرّر.
- تصنيف تلقائي بقواعد (Migros ← سوبرماركت، Turkcell ← اتصالات…). لما تصحّح فئة، بتقدر تخلّيه يتذكّر.
- حسابات متعدّدة بأرصدتها، وسعر الدولار يومي من البنك المركزي التركي (TCMB).
- رمز دخول (PIN)، ونسخة احتياطية بكبسة زر.

## التشغيل على الماك

مرة وحدة بس: تأكّد إنه عندك Python 3.10 أو أحدث. افتح Terminal واكتب:

```bash
python3 --version
```

إذا مش موجود، نزّله من [python.org](https://www.python.org/downloads/macos/).

بعدها:

```bash
git clone https://github.com/moayedz/banke.git
cd banke
./run.sh
```

وافتح **http://localhost:8000** بالمتصفح. أول مرة رح يطلب منك تختار رمز دخول.
⚠️ هاد رمز للتطبيق بس، **ما تحط رمز البنك أبدًا**.

للإيقاف: `Ctrl + C` بالـ Terminal.

## الفتح من الآيفون

1. نزّل **Tailscale** (مجاني) على الماك والآيفون، وسجّل دخول بنفس الحساب على الجهازين.
2. على الماك شغّل: `./run.sh phone` ورح يطبعلك العنوان (شي متل `http://100.x.x.x:8000`).
3. افتحه من **Safari** على الآيفون ← زر المشاركة ← **Add to Home Screen**.

> ليش Tailscale؟ لأنه بيشفّر الاتصال بين جهازينك، وبيشتغل حتى لو كنت برّا البيت.
> بدون Tailscale بيشتغل كمان على نفس الـ Wi-Fi، بس **بس بشبكة البيت**، مش بشبكة الجامعة أو الكافيه.
> الماك لازم يكون شغّال وفاتح البرنامج عشان تفتحه من الآيفون.

## استيراد كشف الحساب

1. ادخل الإنترنت بانكنغ من الماك ← حركات الحساب (Hesap Hareketleri) ← اختار الفترة ← نزّل **Excel**.
2. بالتطبيق: **استيراد** ← اختار الحساب ← ارفع الملف ← **معاينة**.
3. إذا الأعمدة غلط، صحّحها من القوائم وكبس "حدّث المعاينة". بعدين **استيراد**.

نصيحة: احذف الملف من Downloads بعد ما تستورده.

## الأمان 🔒

- البيانات بـ `data/banke.db` على الماك بس. مجلد `data/` **مستثنى من git**، يعني عمره ما بينرفع على GitHub.
- فعّل **FileVault** على الماك (System Settings ← Privacy & Security ← FileVault) عشان القرص كله يكون مشفّر.
- رمز الدخول بينحفظ كبصمة مشفّرة (PBKDF2)، وبعد 5 محاولات غلط بينقفل الدخول 5 دقايق.
- `./run.sh` لحالها بتفتح التطبيق للماك بس. `./run.sh phone` بتفتحه للشبكة، فاستعملها مع Tailscale.
- **نسخة احتياطية:** من صفحة الحسابات ← "تنزيل نسخة احتياطية"، واحفظها بمكان آمن (مثلًا ملف مضغوط بكلمة سر).
  للاسترجاع: سكّر البرنامج وحط الملف مكان `data/banke.db`.
- البرنامج **ما بيطلب ولا بيخزّن** كلمة سر البنك، ولا رقم البطاقة، ولا رموز OTP.

## للمطوّر (إلك أو لإلي 🙂)

```
app/
  main.py        ← الصفحات والروابط
  db.py          ← قاعدة البيانات والفئات والقواعد الافتراضية
  parsing.py     ← قراءة Excel/CSV وفهم المبالغ والتواريخ التركية والتصنيف
  fx.py          ← سعر الصرف من TCMB
  security.py    ← رمز الدخول
  templates/     ← صفحات HTML
  static/        ← التصميم والأيقونات (Chart.js محلي، ما في طلبات لمواقع برّا)
tests/           ← اختبارات
```

تشغيل الاختبارات:

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```
